Rainy AI

A personal Android AI companion powered exclusively by Google Gemini.

Technology

- Kotlin
- Jetpack Compose
- Google Gemini API
- Android Accessibility Service
- GitHub Actions for APK builds

Development roadmap

1. Verify the Android build pipeline.
2. Build the initial Android app.
3. Integrate Gemini chat and personality.
4. Add voice input and speech output.
5. Add app launching and YouTube search.
6. Add user-authorized accessibility automation.
7. Add screen analysis and coding assistance.

Security

Never commit API keys, passwords, signing keys, or other secrets to this repository.

Build goal

Produce a debug APK through GitHub Actions.
